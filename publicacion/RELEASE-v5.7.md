# Radical Cristal — Tito Xeluis v5.7

Modificación personal de Pokémon Cristal para Game Boy Color, basada en el código fuente español de MicaelAlighieri/pokecristal y el trabajo de la comunidad pret/pokecrystal. No es un producto oficial de Pokémon.

## Descarga

Un único archivo jugable: **`Radical Cristal.gbc`** (ROM normal v5.7).

- SHA-256: `d7f6d1067171632c2f24c2c40520c2c7a66b9c75672d13f31dd4215a14eb46e0`
- No necesita ROM base ni aplicar parches. Ábrela con un emulador compatible con Game Boy Color (se obtiene por separado).
- No necesita partida nueva respecto a la 5.6, 5.5, 5.4, 5.3, 5.2, 5.1, 5.0 ni 4.4: guarda dentro del juego y carga el `.sav` con la nueva ROM. No uses estados rápidos de otra compilación. Otra semilla del randomizador requiere partida nueva.
