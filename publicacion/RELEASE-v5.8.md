# Radical Cristal — Tito Xeluis v5.8

Modificación personal de Pokémon Cristal para Game Boy Color, basada en el código fuente español de MicaelAlighieri/pokecristal y el trabajo de la comunidad pret/pokecrystal. No es un producto oficial de Pokémon.

## Descarga

- **`Radical Cristal.gbc`** — ROM normal v5.8. SHA-256: `fac843af81fa454cac9da3e0b83cc25b2124360307c6f22aefe94b20863f1f6b`
- **`Randomizador.html`** — el randomizador sin conexión para esta versión: ábrelo en el navegador, elige tu `Radical Cristal.gbc` y descarga tu ROM aleatorizada. Es libre: descárgalo y compártelo; la ROM base no va incluida.
- No necesitas ROM base ni aplicar parches. Abre la ROM con un emulador compatible con Game Boy Color (se obtiene por separado).
- No necesita partida nueva respecto a la 5.7, 5.6, 5.5, 5.4, 5.3, 5.2, 5.1, 5.0 ni 4.4: guarda dentro del juego y carga el `.sav` con la nueva ROM. No uses estados rápidos de otra compilación. Otra semilla del randomizador requiere partida nueva.

## Novedades de 5.8

2. **Superliga más dura:** Azul, Lance y Rojo con tres legendarios cada uno y Ulex con Dark Lugia como último Pokémon.
3. **Randomizador descargable** desde esta Release.
4. **Dark Lugia por detrás** tiene una imagen nueva, la aportada por el autor.
